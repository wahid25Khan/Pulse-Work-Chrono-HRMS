# Portal API class access

This is a minimal Metadata API package enabling `PWChrono_PortalApi` on the existing Pulse Work Chrono site guest profile. Deploy the Apex class first, then this package. Do not substitute the full, potentially stale source profile for this narrow update.

The API validates the server-issued portal session and delegates to existing authorization and record-ownership checks. This package does not change object, field, record-sharing, or other class permissions.
